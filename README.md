## 👨🏻‍💻 Sobre mim

Sou **Luís Miguel Silva**, estudante de **Desenvolvimento de Sistemas no SENAI-SP**, em Osvaldo Cruz, São Paulo. Estou construindo minha experiência em programação por meio de atividades acadêmicas e projetos práticos, com interesse especial em desenvolvimento Back-End, APIs e criação de aplicações web.

Gosto de entender como cada parte de uma aplicação funciona, desde a estrutura do código até os testes das funcionalidades. Meu foco é evoluir com consistência, escrever código organizado e desenvolver soluções que resolvam problemas reais.

- 🎓 **Formação atual:** Curso de Desenvolvimento de Sistemas — SENAI-SP.
- ⚙️ **Foco de estudo:** lógica de programação, Back-End, APIs REST e métodos HTTP.
- 🌐 **Desenvolvimento Web:** HTML, CSS e JavaScript.
- 🧪 **Ferramentas:** Git, GitHub, VS Code e Postman.
- 🤝 **Projeto em equipe:** Qota — proposta de soluções digitais e sistema de orçamentos para empresas.
- 📍 **Localidade:** Osvaldo Cruz, São Paulo, Brasil.
- 📬 **Contato profissional:** [luis.m.silva8@edu.senai.br](mailto:luis.m.silva8@edu.senai.br).
