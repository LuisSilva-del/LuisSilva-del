## 👨‍💻 Sobre mim

Olá! Sou o **Luís Miguel**, estudante de **Desenvolvimento de Sistemas no SENAI-SP**. Estou desenvolvendo minhas habilidades em programação por meio das aulas e de projetos práticos, buscando entender como as aplicações funcionam desde a interface até a lógica do sistema.

- 🎓 Estudante de Desenvolvimento de Sistemas no SENAI-SP.
- ⚙️ Aprendendo a desenvolver aplicações Back-End e APIs REST.
- 🌐 Praticando HTML, CSS e JavaScript no desenvolvimento web.
- 🧪 Utilizando Git, GitHub, VS Code e Postman nos estudos e projetos.
- 🤝 Participando da **Qota**, iniciativa em equipe para criar soluções digitais para empresas.
- 🎯 Meu objetivo é evoluir continuamente e desenvolver aplicações úteis, organizadas e fáceis de usar.

**O que pratico:** JavaScript, Node.js, organização de rotas e controladores, métodos HTTP e testes de API.
